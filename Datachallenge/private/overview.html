Challenge Overview

This challenge focuses on building a machine learning model to predict daily calories burned (`Calories`) using wearable device data. The dataset integrates physical activity, active distances, sedentary behavior, sleep metrics, and body composition for 33 unique users observed over multiple days.

Your goal is to produce the most accurate predictions possible using RMSE as the evaluation metric. Submit your predictions regularly to climb the leaderboard!

Prediction Task

Objective

Predict the total calories burned in a day (`Calories`) for a given user, based on their activity, sleep, and physiological characteristics.

📊 Evaluation Metric:

RMSE (Root Mean Squared Error)

View RMSE Formulas (Python & R)

Python:

import numpy as np

def calculate_rmse(actual, predicted):
    mse = np.mean((actual - predicted) ** 2)
    return np.sqrt(mse)

R:

calculate_rmse <- function(actual, predicted) {
  mse <- mean((actual - predicted)^2)
  return(sqrt(mse))
}

Formula:

RMSE = √(1/n × Σ(y_actual - y_predicted)²)
