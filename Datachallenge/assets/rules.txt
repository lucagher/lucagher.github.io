📘 Submission Guidelines
=======================
This document explains the exact format required for every leaderboard submission. Files that do not follow these rules are rejected automatically.

📥 File Format
--------------
- Submit **one CSV file** only.
- The file must contain **exactly one column named `prediction`**.
- Include **228 numeric values** (one prediction per row in the test set).
- Do **not** add IDs, dates, row numbers, blank rows, or extra separators.

📌 Ordering Rules
-----------------
Predictions must follow the same order as `Datachallenge/assets/test.csv`. The first prediction corresponds to the first test row, the second prediction to the second row, and so on.

Example test rows (simplified)
```
Id,Date
A,2020-05-06
A,2020-05-07
A,2020-05-08
...
B,2020-05-10
```

Your CSV must look like:
```
prediction
value_for_row_1
value_for_row_2
value_for_row_3
...
value_for_row_228
```

❌ Submissions that will be rejected
-----------------------------------
- Additional columns like `Id`, `Date`, `row_number`, etc.
- Different column name (it must be `prediction`).
- Changing the row order or skipping rows.
- Providing fewer or more than 228 predictions.
- Exporting with index numbers generated automatically by pandas/R.

📤 Export templates
-------------------
R
```
submission <- data.frame(prediction = preds)
write.csv(submission, "submission.csv", row.names = FALSE)
```

Python
```
import pandas as pd
submission = pd.DataFrame({"prediction": preds})
submission.to_csv("submission.csv", index=False)
```

📝 Pre-flight checklist
-----------------------
✔ Column name is exactly `prediction`.
✔ 228 numeric rows (no blanks, no text).
✔ Order identical to `test.csv`.
✔ Saved as CSV without index or hidden metadata.
✔ File encoding is UTF-8 (default from R/pandas).

📂 Dataset Description
======================
This dataset contains daily-level information collected from Fitbit wearable devices. It integrates physical activity, active distances, sedentary behavior, sleep metrics, and body composition for multiple users across several days.

Each record represents user activity in a specific date
 
 🎯 Prediction Task (Regression)

  🧍 Identifiers & Metadata
 
  | Variable | Type    | Description                              |
  | -------- | ------- | ---------------------------------------- |
  | `Id`     | numeric | Unique anonymized participant identifier |

  | Variable                   | Type    | Description                                    |

  | `VeryActiveDistance`       | numeric | Distance during very active periods            |
  | `ModeratelyActiveDistance` | numeric | Distance during moderate activity              |
  | `LightActiveDistance`      | numeric | Distance during light activity                 |
  | `SedentaryActiveDistance`  | numeric | Distance during sedentary activity (usually 0) |
  | `VeryActiveMinutes`        | numeric | Minutes of very intense activity               |
  | `FairlyActiveMinutes`      | numeric | Minutes of moderate activity                   |
  | `LightlyActiveMinutes`     | numeric | Minutes of light activity                      |
  | `SedentaryMinutes`         | numeric | Minutes of inactivity/sitting                  |
